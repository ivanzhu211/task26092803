# worktime

工时分类计算库，供上层考勤服务调用（无接口层、不落盘）。
输入工会谈判单位的规则配置与一批打卡记录，按员工、按周返回
正常 / 加班 / 双倍三类工时的分段结果，并附来源打卡记录号与异常清单。

## 用法

```go
cfg := worktime.Config{
    RoundMinutes:    5,     // 取整单位：5、6 或 15
    GraceMinutes:    7,     // 上班晚于排班开始的宽限
    DisableDailyOT8: false, // 关闭每日 8 小时加班规则（双倍照常）
}
results := worktime.Compute(cfg, punches, corrections)
// results: []worktime.EmployeeResult，按员工号、周起始（周日 0 点）排序
```

## 处理流水线

1. `normalize.go`：应用更正（同一记录以提交时间最晚者为准，支持改时与作废），
   再按取整前时间去重（同员工同类打卡 2 分钟内丢弃后者）。
2. `rounding.go`：按 5/6/15 分钟就近取整，正中向上；上班打卡晚于排班开始
   不超过宽限的按排班开始计，不再取整。
3. `shifts.go`：上班与之后的下班配对成班次；缺卡、跨度超 16 小时列异常。
   成对用餐按实际时长扣除；不成对或落在班次外的用餐打卡列异常；
   无用餐打卡且跨度超 6 小时的班次，自动扣除满 5 小时起的 30 分钟。
4. `classify.go`：班次归入取整后上班时刻所在日期，当日超 8 小时记加班、
   超 12 小时记双倍；跨周班次在周日 0 点切开；每周正常工时累计超 40 小时的
   部分改记加班（已记加班 / 双倍的不计入、不重复加价）。
