# worktime

工时分类计算库。输入工会谈判单位的规则配置与一批打卡记录，输出按员工、按周的正常 / 加班 / 双倍分钟数与分段明细，供上层考勤服务直接调用，无接口层、无落盘。

## 用法

```go
res := worktime.Calculate(worktime.Input{
    Config: worktime.Config{
        RoundingMinutes: 5,   // 5、6 或 15
        DailyOTEnabled:  true, // 关闭后每日 8h 加班规则停用，12h 双倍照常
    },
    Punches:     punches,     // 任意顺序，含上班/用餐开始/用餐结束/下班
    Corrections: corrections, // 更正或作废，指向原记录号
})
// res []EmployeeResult：按员工号排序；每周含三类分钟数与带来源记录号的分段；
// 异常（缺卡、超 16h、用餐不成对、班次外用餐）单独列出。
```

## 计算管线

1. `normalize.go`：应用更正（同记录取最晚提交）→ 同类 2 分钟去重（按取整前时间）→ 取整（正中向上）与排班 7 分钟宽限。
2. `shifts.go`：上下班配对成班次（缺卡、超 16h 列异常）→ 用餐打卡配对扣除，无用餐且超 6h 自动扣 5h 起 30 分钟。
3. `classify.go`：按归班日期做 8/12h 日分类 → 周日 0 点切周 → 周 40h 规则（已记加班/双倍不计入）。
4. `calc.go`：按员工分组串联各阶段，输出确定性结果。
